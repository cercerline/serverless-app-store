怎么用

  1. 点「先预览一遍」看效果（不录制，随时可重来）
  2. 满意后点「开始录制」，页面会自动播放并录制，不要切换标签页
  3. 播放结束会自动下载一个 .mp4 文件，直接上传 B 站即可
  4. 封面图：打开 video.html?t=55&clean=1 然后截屏，得到干净的 1920×1080 画面

为什么用实时录制而不是直接导出

浏览器没有「渲染成视频文件」的接口，但可以一边渲染一边录。 好处是动画、中文字体、二维码全部由浏览器原生绘制，不需要安装任何图形库或转码工具。 用新版 Edge 或 Chrome 打开，录出来就是 H.264 + AAC 的 MP4；旧浏览器会自动退回 WebM。

提示：录制时会同时采集系统声音吗？不会——配音是通过 Web Audio 直接混入录制流的， 所以不需要任何录屏权限，也不会有环境噪音。
